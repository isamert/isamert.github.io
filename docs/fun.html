my watchlist

This page contains my watchlist with my ratings. I keep what I watch in a single org file, as explained here. I also use a package that I wrote to maintain that file, called orgmdb.el. I export that file as JSON, using this code (which itself is part of this website, see the next section) and serve in this page using some javascript to make it interactive and filterable etc.

My memory is a bit weak, so I find it hard to talk about movies I watched but this page served me very well on this regard. Whenever a movie talk happens, I open up this page to refresh my memory. I also observed that people organically start scrolling and start discussions about the movies we both saw which I find quite amusing.

source of this website

The interesting part about this website is everything is generated from single org-mode file (including all the assets) and the code that generates it is even in the file itself. 11Only exceptions are the image files and my resume. It is also possible to embed them into the file using some base64 shenanigans but has no practical value, so I kept them separate. Resume itself is not really part of the blog itself, so I also kept it outside. To list a few properties of it: It has a templating system, makes use of org-babel and noweb syntax heavily, you can embed arbitrary elisp anywhere and make it output HTML,22Or you can also use the shr package to render HTML using elisp lists, not powerful as Clojure's hiccup but it's still very good! it has tagging system, generates RSS feeds/pages, contains a local server for development…
